# Phoenix NextGen Kits website preview

Responsive static homepage for the Phoenix NextGen teamwear concept.

## Deploy
Upload `index.html` and the complete `images` folder to the root of your GitHub repository. Vercel should redeploy after the commit.

## Notes
- Original supplied design sheets are included unchanged in `images/` and can be opened from each collection.
- Model photos are AI-generated visual mockups, not confirmed photos of manufactured garments; refer to the original design sheets for exact design details.
- Instagram footer points to https://www.instagram.com/phoenixnextgen_/
- This is a front-end preview only. It does not include production checkout, real inventory, secure admin authentication, or order management.
